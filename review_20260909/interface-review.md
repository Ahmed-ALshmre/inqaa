# مراجعة تحديث الواجهات وفريق العمل — 9 سبتمبر 2026

أعيد تنظيم التصميم المشترك للصفحات، وتبسيط التنقل، وتجميع الإعدادات مع البحث. توسعت مساحة المحادثة وانتقلت بيانات الزبون والأدوات إلى نافذة مستقلة. اختصارات الرد أصبحت إجراءات للكتالوج والصور وتثبيت الطلب، مع معاينة الصور قبل إرسالها. تظهر شارة ماسنجر أو إنستغرام حسب المصدر المسجل للمحادثة؛ المصدر غير المعروف لا يُخمن.

في المستشار، بقي حقل الكتابة ضمن ارتفاع الشاشة وانتقلت الذاكرة والاقتراحات وخيارات التحليل إلى نوافذ. التمرير يتم داخل سجل الرسائل، وزر آخر رسالة ينقل إلى نهايته دون تحريك الصفحة كاملة.

أضيفت حسابات الموظفين مع خمس صلاحيات اختيارية وتحقق من الصلاحيات على الخادم. تعطيل الحساب أو تغيير صلاحياته يبطل جلساته القديمة. موظف الرد لا يستطيع إنشاء طلب من خلال إرسال مسودة الذكاء الاصطناعي دون صلاحية الطلبات. الصلاحيات تشمل كل المتاجر، وإدارة الموظفين والنسخ الاحتياطية وحذف المحادثات تبقى للمالك.

- نجحت اختبارات JavaScript الخاصة بإرسال الصور دون تكرار والحفاظ على مسودة الرد.
- فُحصت الواجهة بمتصفح Chrome آلياً على عرض 1440 و390 و360 بكسل. اختُبر عرض قصير بارتفاع 480 بكسل لمحاكاة المساحة المتاحة عند الكتابة.
