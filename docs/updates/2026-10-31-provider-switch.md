# إعادة الفاتنة إلى Chatwoot ونقل عالم البراءة إلى Zernio

هذا التحديث ينقل تعديل الربط المحلي إلى أحدث `main` من GitHub، مع إبقاء
إصلاح السعر في طلب #10 على فرعه المستقل. لا ينقل هذا الكود محادثات قديمة ولا يعيد إرسالها.

## السلوك

- مفتاح تفعيل مستقل لكل متجر؛ لا تُفعّل أي هجرة افتراضيًا.
- حساب Zernio يحدد المتجر والمنصة، ويُرفض مسار webhook المخالف قبل إنشاء سجلات.
- الاستقبال والإرسال وربط الإعلان بالمنتج وسياق الصور تستخدم متجر المحادثة نفسه.
- يتجاهل Chatwoot المتجر المفعّل في Zernio فقط لتجنب الرد المكرر.
- الإعداد الناقص لا يحوّل متجرًا مفعّلًا في Zernio تلقائيًا إلى مزود آخر.
- تبقى المحادثات القديمة مقروءة، ويحتاج إرسالها إلى مسار مطابق لمزودها.

## التفعيل الحي

هذه خطوات تشغيل منفصلة عن رفع الكود. يجب التحقق من الحسابات الحالية وقت التطبيق؛
لا تستخدم حسابات فاتنة القديمة لربط الأطفال ولا تضع الأسرار في Git.

1. انشر الكود مع الحفاظ على قاعدة البيانات والصور والأسرار.
2. اضبط `MESSAGING_PROVIDER=chatwoot`، و`ZERNIO_AL_FATENA_ENABLED=0`،
   و`ZERNIO_BARAAH_KIDS_ENABLED=1`، واربط حسابي الأطفال الفعليين في `ZERNIO_ACCOUNTS`:

   ```json
   {
     "<kids-facebook-account-id>": {"store_id": "baraah-kids", "platform": "facebook"},
     "<kids-instagram-account-id>": {"store_id": "baraah-kids", "platform": "instagram"}
   }
   ```

   هذه معرّفات حسابات Zernio ذات 24 خانة سداسية، وليست معرّفات إعلانات.
   أبقِ مفتاح API وسر توقيع webhook الحاليين.
3. احفظ روابط صناديق Chatwoot لكل متجر، وتأكد من بقاء صناديق فاتنة مرتبطة بـ`al-fatena`.
4. تحقق من `/api/zernio/diag`: الأطفال `ready=true` وفاتنة `enabled=false`.
   يعرض `/health` بند `zernio_baraah_kids` عند تفعيل الأطفال.
5. حدّث اشتراك Zernio الموجود إلى `/zernio/webhook/baraah-kids`،
   مع الحدثين `message.received` و`referral.received` وحسابي الأطفال فقط.
   أبقِ سر التوقيع وفعّل الاشتراك، وتجنب إنشاء اشتراك مكرر.
6. تحقق من توجيه Meta: فاتنة إلى Chatwoot والأطفال إلى Zernio.
   وصول حدث `standby=true` لا يشغّل ردًا، حتى لو كان اختبار webhook ناجحًا.
7. تحقق برسائل جديدة من حسابات اختبار مصرح بها لكل متجر ومنصة، وصحة الكتالوج
   ورد واحد فقط وحفظ الإحالة عند وصولها. لا يُعاد تشغيل التاريخ على الزبائن.

## الاختبارات

`test_provider_switch_oct31.py` يغطي المنصتين، عزل الحسابات والكتالوج،
عودة فاتنة إلى Chatwoot، منع استقبال الأطفال المكرر، والمسار المخالف والإرسال عبر متجر آخر.
تُشغّل الاختبارات في قاعدة مؤقتة مع حجب الشبكة:

```sh
python -X utf8 -m account_app.tests.run_isolated
```

التحقق على أحدث `main` بتاريخ 2026-10-31: نجحت **1496 حالة اختبار** في
204.914 ثانية، مع حجب الاتصالات الخارجية وقاعدة بيانات مؤقتة.
يشمل ذلك اختبارات النقل الخمسة الجديدة. هذه نتيجة محلية وليست إثبات تفعيل النقل الحي.

## الرجوع

أوقف `ZERNIO_BARAAH_KIDS_ENABLED=0` وأعد توجيه Meta إلى Chatwoot عند الحاجة.
لا تُعد تفعيل فاتنة عبر Zernio بمعرّفات حسابات قديمة دون التحقق منها.
تبقى المحادثات والطلبات والإعلانات محفوظة.
