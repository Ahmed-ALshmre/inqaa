# مستشار Sol قبل التحويل البشري — 8 نوفمبر 2026

طلب المالك إضافة `openai/gpt-6.1-sol` للمساعدة في الأسئلة الصعبة أو فقدان السياق أو قرار تحويل سببه عجز البوت، مع إبقاء موديلات الرد والتعرف الحالية كما هي. لا يغيّر هذا العمل تجربة Terra/Gemini غير المفعّلة، ولا يربطها بالإنتاج.

## السلوك

1. الرد الطبيعي والحساب والحجز المكتمل يستمران في المسار الحالي. لا تُطلب الاستشارة لكل رسالة.
2. عند عجز الموديل، أو إعادة طلب منتج/بيانات معروفة، أو إسقاط جزء من سؤال مركب، أو ظهور رد غير مسند، يستشار Sol مرة واحدة. الأسئلة الناقصة تمر عليه قبل إنشاء المراجعة وإيقاف المحادثة؛ قد يجد الجواب في سياق لم يفهمه المسار الأول.
3. يستلم نص المحادثة وذاكرة البيع والمنتجات ذات الصلة وسلة مستعادة صحيحة إن توفرت، ووجود الرقم والعنوان، وحقائق التوصيل وتوجيه الموظف. لا ترسل الصور أو الصوت للمستشار. تبقى معالجة الصور والصوت بموديلاتها الحالية.
4. يعيد قرار `assist` وتوجيهاً موجزاً أو `needs_human`. لا يعيد رسالة زبون أو أمراً تنفيذياً. الموديل الرئيسي المضبوط للمتجر يصيغ محاولة أخيرة باللهجة العراقية، وتطبق عليها فحوص السعر والمخزون والسلة والموافقة والحفظ المعتادة.
5. إذا قرر المستشار الحاجة للإنسان، أو فشل استدعاؤه/مخططه/مهلته، أو بقي الرد بعده غير صالح، يسجل تدخل بشري حقيقي ويتوقف AI في المحادثة بصمت. تبقى اختيارات السلة محفوظة للمراجعة. لا تؤكد حجوزات أو ترسل تنبيهات تحويل للزبون.

طلبات الموظف الصريحة، وأسئلة الهوية التي تتطلب التحويل، والإلغاء/التغيير/المتابعة التي تحتاج إجراء بعد الحجز، والصورة غير المعروفة لا تتجاوز مساراتها البشرية. الإيقاف العام للمتجر أو المحادثة محترم. المعاينة البشرية لا تبدأ استشارة آلية جديدة.

اعتراض السعر سؤال بيع، وليس إذناً للمستشار بتغيير التسعير. وجود توجيه من المستشار لا يعالج حقيقة غير موجودة ولا يختلق ليكرا أو قياساً أو توفر لون. يعتمد آخر اختيار وتصحيح صريح؛ لا يطلب موافقة شراء ثانية بعد رغبة شراء واضحة.

## التنفيذ والتتبع

- `account_app/reply_consultant.py`: سياق مستقل لكل استدعاء/متجر عبر `ContextVar`، برومبت الاستشارة، تنقيح البيانات، ومخطط JSON صارم بأربعة حقول. يرفض منتجاً خارج القائمة وحقول تنفيذ إضافية.
- `account_app/app.py`: يبقي `call_main_ai` واجهة المسار، مع تأجيل كتابة مراجعة السؤال حتى انتهاء محاولة المستشار. لا يوجد استدعاء آخر لـSol بسبب إعادة صياغة الرد في نفس الرسالة.
- `ai_transport.py`: خيارات اختيارية لمحاولة واحدة وميزانية زمنية. للمستشار40 ثانية ولإعادة صياغة الرئيسي45 ثانية، مع بقاء الإعدادات الافتراضية لبقية طلبات الموديلات.
- يسجل الاستهلاك في `ai_usage_events` بالغرض `reply_consultation` والموديل المحدد. وسم `_reply_consultation` يوضح المحاولة وحالتها دون حفظ نص الاستشارة داخل رسالة الزبون. الفشل يحتفظ بسبب تشخيصي داخلي.
- لا تُطبع المفاتيح ولا تدخل في الملفات أو التقارير. تزال حقول بيانات الاتصال والروابط والوسائط من سياق المستشار، مع تنقيح أرقام الهاتف المتصلة أو المفصولة في النص. يبقى نص الأسئلة ذاكرة للفهم، لا أوامر نظام.
- السياق محدود بمنتجات ذات صلة وسجل حديث وبحد نصي80 ألف حرف؛ إذا تعذر حفظ هذا الحد دون حذف السياق الضروري يتحول بأمان للمراجعة قبل الاستدعاء المدفوع.

الميزة مفعلة افتراضياً عند نشر الكود؛ `REPLY_CONSULTANT_ENABLED=0` مفتاح تراجع تشغيلي. لا يعدّل أي `ai_main_model` أو موديل صور/صوت أو حالات تشغيل المتاجر. تستخدم مفتاح OpenRouter المكوّن للنظام، ولا تستبدله بمفتاح اختبار.

## التحقق

```powershell
python -X utf8 -m account_app.tests.run_isolated
python -X utf8 tools/check_reply_consultant_live.py --ask-key
```
