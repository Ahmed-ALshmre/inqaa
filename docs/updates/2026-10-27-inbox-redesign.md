# شريط المحادثات وثبات التحميل — 27 أكتوبر 2026

كان التحديث الدوري يعيد بعض القوائم المصفّاة من 40 محادثة محمّلة إلى أول 20، ويُعاد إنشاء جميع الصفوف عند تغيرها. كذلك كان إخفاء أدوات التصفية تلقائياً أثناء التمرير يغيّر ارتفاع مساحة القائمة ويطلق أحداث تمرير متتابعة. أظهر اختبار المتصفح قبل الإصلاح الانتقال من 40 إلى 20 بعد تحديث فلتر التدخل البشري.

أصبحت أدوات البحث والتصفية ثابتة، مع بحث ومتجر متجاورين، حالات مرتبة، ألوان هادئة مميزة للمتاجر والتنبيهات، وصفوف أوضح. شريط التحميل أسفل القائمة يحجز ارتفاعاً ثابتاً ويعرض زر تحميل المحادثات الأقدم وإعادة المحاولة وحالة نهاية القائمة. لا يُفرّغ التحديث الدوري القائمة ولا يخفي الأدوات، وتُضاف المحادثات القديمة دون إشعارات وصول رسائل جديدة.

تُحدّث الصفوف بحسب معرف المحادثة ويُعاد استخدام عناصرها؛ لا يُعاد بناء صف لم يتغير محتواه. يُحفظ معرف أول صف ظاهر وإزاحته داخل القائمة قبل التغيير، ثم يستعاد موضعه بعد الإضافة أو الترتيب. بقي التركيز بلوحة المفاتيح على العنصر نفسه. أُزيل تقدير ارتفاع الصفوف غير المرئية الذي كان يغيّر قياسات القائمة، وثُبت عرض حدود الصف عند اختياره.

يجلب التحديث الدوري النافذة المحمّلة حتى حد الخادم البالغ 100 صف، ويحتفظ بذيل الصفحات الأقدم في الذاكرة. يكون الجزء المحدث مرجعاً لإزالة الصفوف التي لم تعد ضمن مقدمته. لا يسمح لتحديث خلفي بإلغاء طلب تحميل صفحة أقدم. ترتبط النتائج بتوقيع البحث والتصفية؛ استجابة بحث قديم أو تعافي طلب فاشل لا يخلطان نتائج قائمتين مختلفتين. يعيد زر المحاولة الطلب الفاشل نفسه، مع إبقاء البيانات السابقة ظاهرة عند انقطاع الاتصال.

## التحقق

- `tools/preview_inbox.py` يشغل التطبيق على `127.0.0.1:5117` بقاعدة مؤقتة تضم 320 محادثة اصطناعية. يعطل أعمال الخلفية والمزودين الخارجيين؛ لا يقرأ قاعدة الإنتاج ولا ينشئ إرساليات للزبائن.
- `account_app/tests/test_inbox_browser.cjs` اجتاز 14 فحصاً سلوكياً بمتصفح Edge فعلي: ثبات DOM والتركيز، بقاء الصفحات المصفاة، وصول محادثة فوق موضع القراءة، تجاوز حد 100 صف، التمرير لتحميل المزيد، ترتيب الأقدم والأعلى اهتماماً، تزامن الطلبات، الفشل وإعادة المحاولة، الوصول إلى جميع المحادثات الـ320 دون تكرار، البحث السريع، وتعافي البحث بالخلفية والحالات الفارغة.
- فُحص التخطيط بصرياً وعلى المتصفح بعروض 320 و360 و390 و768 و1024 و1440 دون تمرير أفقي غير مقصود، مع مراجعة لقطات الهاتف والكمبيوتر.
- اجتازت اختبارات API الخاصة بالفلاتر والإحصاءات 8 حالات، واجتازت اختبارات JavaScript الحالية للمسودات والصور وحماية تبديل المحادثة.
- حُدثت إصدارات ملفات الواجهة وذاكرة Service Worker لتصل الملفات الجديدة إلى التطبيق المثبت أيضاً.

لتكرار فحص المتصفح: شغّل `python tools/preview_inbox.py` ثم `node account_app/tests/test_inbox_browser.cjs` مع إتاحة مكتبة Playwright في بيئة Node ووجود Microsoft Edge، أو ضبط `INBOX_QA_BROWSER` لقناة متصفح مثبتة. النتائج واللقطات تحفظ محلياً داخل `outputs/inbox-qa/` ولا تُضمَّن بيانات محادثات خاصة في Git.
