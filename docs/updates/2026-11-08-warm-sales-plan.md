# خطة إعادة بناء محادثة البيع — البحث والاستشارة أولاً

أُعدت هذه الخطة قبل تعديل تعليمات أو منطق التجربة الجديدة، استجابة لرفض المالك برودة الردود. الهدف محادثة عراقية دافئة تقود لشراء مناسب وحجز صحيح. نطاق التنفيذ الحالي تركيبة Terra للإدارة وGemini 3.8 Flash للصياغة في بيئة معزولة، دون نشر أو تغيير نموذج المتاجر الحي.

## 2. تشخيص التجربة المرفوضة

1. الافتتاح أعطى السعر وحده دون سبب للاهتمام أو خطوة اختيار؛ أصبحت المحادثة أجوبة FAQ.
2. قيود «لقب واحد» و«فقاعتان فقط» و«جملتان غالباً» ضيقت الأسلوب حتى مع سؤال يحتاج شرحاً وطمأنة.
3. لم تسجل الخطة مناسبة الشراء أو سبب التردد أو نوع الخطوة القادمة بوضوح؛ لذلك كانت تطلب رقمًا وعنوانًا قبل حل الحيرة أحياناً.
4. قُيّمت سلامة الحفظ أكثر من جودة الترشيح والدفء. نجاح الحفظ لا يثبت أن الزبون أحب الرد أو اقتنع به.

## 3. مراحل الحوار ومتى نتجاوزها

| المرحلة | الهدف | سلوك الرد والخطوة التالية |
| --- | --- | --- |
| افتتاح منتج معروف | دفء وفائدة فورية وفتح اختيار | ترحيب أول مرة، جواب واضح، ميزة من بيانات القطعة تخدم السؤال، ثم لون أو قياس أو حاجة ناقصة. |
| فهم الحاجة | معرفة ما يناسبها بأقل أسئلة | المناسبة والمستفيد والتفضيل عند الحاجة فقط؛ لا نسأل عما قالته. |
| ترشيح | مساعدتها على حسم الاختيار | خيار أو خياران فعليان مع سبب مرتبط بذوقها أو حاجتها؛ الرأي الذوقي يظهر كرأي. |
| اعتراض وثقة | إزالة سبب التوقف الحقيقي | نعكس القلق ونجيب بحقيقة تخصه ثم خطوة مناسبة، دون تكرار السعر أو طلب البيانات تلقائياً. |
| مساومة | تقريب الاتفاق بمرونة | خصم مطلوب حتى2000 للطلب متعدد القطع. طلب أكبر يقابل بسعر مسموح ودود؛ لا تحويل موافقة ولا خصم متراكم. |
| اختيار جاهز | تحويل الرغبة إلى حجز | طلب الرقم والعنوان أو الناقص منهما فقط. استفسار السعر وحده ليس موافقة شراء. |
| بيانات مكتملة | تنفيذ الحجز فوراً | حفظ حقيقي ثم نص تأكيد المالك حرفياً. لا اختراع سؤال إضافي لمجرد إنهاء الرد بسؤال. |
| بعد الحجز أو تعديل | خدمة دقيقة ومريحة | تذكر الطلب وتعديل نفس السجل. لا ادعاء تجهيز أو شحن دون إجراء. الشكر يختتم بدفء دون إعادة البيع. |
| انسحاب أو طلب موظفة | احترام رغبة الزبون | انسحاب واضح: ختام ودود بلا ضغط؛ مراجعة لازمة: تحويل صامت وإيقاف الرد وفق متطلبات المالك. |

المراحل مرنة: الزبونة التي تبدأ بالمنتج واللون والقياس والرقم والعنوان لا تمر باستبيان. تذهب للحفظ مباشرة بعد التحقق من السعر والاختيار والقبول.

## 4. طريقة بناء كل رد

Terra يحدد **مرحلة الحديث، غرض الزبونة، المناسبة والمستفيد، التفضيلات، الاعتراض، ما نعرفه، ما ينقص، والفعل التالي**. ثم يختار الحقائق ذات الصلة، وفكرة كل فقاعة وسبب تقسيمها. هذه خلاصة تنفيذية وليست تفكيراً داخلياً.

Gemini يصوغ حواراً عراقياً حيوياً، يستحضر كلامها ويستعمل «حبيبتي، كلبي، يروحي، من عيوني» حسب المخاطبة والسياق. نزيل عداد الألقاب؛ نراجع التكرار الآلي والمبالغة في القراءة بدلاً من منع الدفء برمجياً. التحية أول المحادثة فقط، مع استجابة طبيعية للمجاملة لاحقاً دون نسخ الافتتاح.

الرد النشط يجمع حسب الحاجة: **جواب + سبب اهتمام حقيقي أو ترشيح + طمأنة عند وجود قلق + خطوة تالية سهلة**. ليس شرطاً حشرها كلها في كل دور. آخر فقرة في مجموعة بيع مفتوحة تحمل سؤال متابعة مناسباً أو طلباً واضحاً للناقص. الاستثناءات: الحفظ المنفذ، تعديل مكتمل، شكر بعد الحفظ، انسحاب صريح، وتحويل بشري.

مثال أسلوب مقترح قبل الاختبار، وليس نصاً ثابتاً ولا ناتج موديل مقاساً:

- «هلا بيج حبيبتي، هذا بـ24 ألف وخامته تركي درجة أولى 🌷»
- «شكد قياسج كلبي حتى أشوفلج ألوانه؟»

الأرقام والصفات تستبدل ببيانات المنتج الفعلي؛ لا يشتق من الخام التركي أنه بارد أو لا يشف، ولا من وجود44 أنه يلائم جسمها قطعاً.

## 5. عدد الرسائل وتقسيم الطويل

| العدد | الحالة المناسبة | مثال بنية المجموعة |
| --- | --- | --- |
| 1 | معلومة ناقصة واحدة، جواب صغير، شكر أو إقرار تعديل | حفظ الرقم ثم طلب العنوان وحده. |
| 2 | أغلب البدايات وعرض اختيار بسيط | جواب دافئ ذو فائدة، ثم سؤال اختيار. |
| 3 | خوف يحتاج طمأنة أو مقارنة تحتاج شرحاً | اعتراف بالقلق، حقيقة تطمئن، ثم الخطوة المناسبة. يمكن دمج أي فقاعتين إذا أقصر. |
| 4 | عدة أسئلة مختلفة في رسالة واحدة | جواب السعر، القماش، التوصيل والفحص، ثم اختيار مناسب؛ دون إعادة معلومة. |
| 5 | رد مركب فعلاً بخمس وحدات معنى | مقارنة أو تفاصيل طلب متعدد مع اعتراض وسؤال ختامي. حالة نادرة، وليست هدفاً لزيادة عدد الرسائل. |

كل فقاعة فكرة مكتملة؛ لا نفصل «هلا» وحدها لتكثير الفقاعات، ولا نختم كل فقاعة بسؤال. الطويل يقسم عند اكتمال المعنى، وتظل الأرقام مع تفسيرها. الصور مرفقات لا تحتسب فقاعات نصية: تمهيد نصي، ثم الصور، ثم تعليق أو سؤال اختيار عند الحاجة. نص تأكيد الحجز استثناء متماسك ينقله البرنامج كما هو.

تُجهز المجموعة كاملة قبل العرض. في الاختبار يُحاكى إرسالها بترتيب أحداث؛ إذا وصلت رسالة أحدث يتوقف ما بقي ويعاد القرار وفق أحدث سياق. لا ندعي اختبار تسليم الصور أو مقاطعة Messenger الفعلية بهذه المحاكاة.

## 6. التنفيذ بعد هذه الخطة

1. استبدال تعليمات الرد القديمة بتعليمات مراحل البيع والدفء، وإزالة حد اللقب والفقاعتين.
2. توسيع قرار Terra ومخطط رد Gemini إلى1–5 مع هدف لكل فقاعة وخطوة حجز واضحة.
3. فصل فحوص صحة الحقائق والتنفيذ عن ملاحظات الأسلوب؛ أخطاء الحساب والإجراءات توقف الرد، والدفء لا يعاقب بسبب عدد الألقاب.
4. إضافة تقسيم الرسائل وترتيب الصور وإلغاء بقية المجموعة عند رسالة أحدث في مُرسل الاختبار المعزول.
5. إبقاء أدوات السعر والخصم والقبول والحفظ ومنع التكرار ونص المالك ثابتة وظيفياً.

## 7. الاختبار ومعايير قبول النسخة التجريبية

- محادثات كاملة تبدأ بسؤال سعر أو سؤال غامض، ثم اختيار وتردد ومساومة وبيانات متفرقة وتغيير بعد الحفظ.
- حالات رد1/2/3/4/5، وحدات معنى وسؤال ختامي واحد، وعدم إرسال4–5 لسؤال سعر بسيط.
- لباس نسائي وأطفال أو أكثر من منتج بحسب اللقطة المتاحة؛ المخاطبة تفرق بين المشتري والمستفيد.
- اختبار مستقل لزبونة محاكاة تتفاعل مع الرد بدلاً من أسئلة تنتهي دائماً بموافقة مكتوبة، مع احتمال الانسحاب.
- اختبار المقاطعة وإلغاء بقية الفقاعات، وعدم تكرار سؤال معروف، والحفظ الفوري، والخصم المحدود، والسعر المشروط، والطلب المكرر، والتحويل الصامت.
- قياس آلي لصحة السعر والحفظ والإجراءات والنص الثابت والتقسيم. وتقييم نوعي منفصل للدفء والترغيب وفهم الاعتراض والخطوة التالية، مع عرض الحوار حرفياً للمالك.
- نحتفظ بالمحاولات المرفوضة والبدائل الحتمية ولا نخفيها. لا نعتمد اختيار أفضل مقتطف وحده كدليل جودة كل المحادثة.

التحسن التجاري الحقيقي يحتاج لاحقاً تجربة حية متكافئة تقيس الاختيار ثم إرسال البيانات ثم الحفظ والإلغاء، دون نسبة مبيعات مضمونة. تنفيذ هذه الخطة في التجربة لا يعني نشرها أو ربط أدواتها الجديدة بمحاسبة وإرسال الإنتاج.
