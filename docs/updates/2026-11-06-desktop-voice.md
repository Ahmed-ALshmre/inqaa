# واجهة الكمبيوتر وتسجيل الصوت

- من عرض 1024px يصبح التنقل جانبياً، مع رأس عمل واضح وقائمة محادثات مستقلة ومساحة رسائل أوسع وأزرار إرسال مناسبة للكمبيوتر واختصار لوحة المفاتيح.
- من عرض 1440px تظهر بيانات الزبون والمنتجات والإجراءات بجانب المحادثة. تنتقل لوحة التحكم نفسها إلى النافذة على الشاشات الأصغر، دون نسخ الحقول أو فقد إجراءاتها.
- تبقى واجهة الموبايل مستقلة، ويحل شريط التسجيل مكان صف الكتابة أثناء تجهيز الرسالة الصوتية، مع الاحتفاظ بالمسودة النصية.
- التسجيل يعرض حالة تشغيل الميكروفون، المدة، زر الإيقاف، ثم مشغلاً بزر تشغيل وتقديم وإعادة تسجيل وحذف وإرسال. تقتصر حركة المؤشر على أثناء التسجيل وتحترم تقليل الحركة.
- يبقى الحد الأقصى دقيقة واحدة. يُغلق الميكروفون وتُلغى المسودة عند تبديل المحادثة أو مغادرة الصفحة. لا يبدأ التسجيل عند وصول إذن متأخر لمحادثة سابقة، ولا يعيد انتهاء إرسال سابق تحميل محادثة أخرى. يبقى التسجيل متاحاً لإعادة المحاولة عند رفض الإرسال.
- لم تتغير واجهة API أو مزودات الرسائل أو قاعدة البيانات. أُخرج منطق التسجيل إلى ملف مستقل مع تحديث إصدارات الأصول ومخبأ التطبيق.

## التحقق

نجحت 44 حالة Python تشمل إرسال الصوت والصلاحيات والمراجعات ومساحة العمل، وست مجموعات JavaScript تشمل حالات التسجيل والمعاينة والإرسال وإلغاء المحادثات ونقل لوحة التحكم بين النافذة وعمود الكمبيوتر. نجح فحص قواعد التنسيق عند عروض 320 و390 و768 و1024 و1280 و1440 و1920px، مع فحص القوالب وروابط الأصول وعدم تكرار المعرّفات. لم يُستخدم ميكروفون حقيقي أو تُرسل رسائل لزبائن أثناء الاختبارات.

الفحص البصري الفعلي وتوافق إذن الميكروفون يعتمدان على الجهاز والمتصفح؛ فحوص التسجيل المحلية استخدمت MediaRecorder تجريبياً. حالة النشر تُثبت بسجلات GitHub وRailway وفحص الأصول المنشورة.
