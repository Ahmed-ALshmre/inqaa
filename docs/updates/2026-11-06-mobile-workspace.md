## التحقق

نجحت 73 حالة Python تخص مساحة العمل والإرسال والصور والصلاحيات وChatwoot والإحصائيات والوسائط. نجحت 72 داخل البيئة المعزولة؛ اختبار استبدال ملف ذاكرة المستشار أعطى WinError 5 داخل صندوق ويندوز ونجح منفرداً خارجه باستخدام ملفات مؤقتة ومنع الشبكة. نجحت أيضاً مجموعات JavaScript الثلاث:

```text
node account_app/tests/test_image_composer.cjs
node account_app/tests/test_dashboard_images.cjs
node account_app/tests/test_dashboard_ai.cjs
```

تم فحص صياغة Python وJavaScript، والقوالب ومسارات الأصول. المعاينة البصرية تعذرت: المتصفح المدمج لم يصل إلى عنوان localhost، ثم أوقفت أداة التحكم بويندوز عملها لعدم قدرتها على التحقق من عنوان المتصفح. لذلك تبقى مطابقة الشكل النهائية على الأجهزة الفعلية غير مؤكدة. لم تُرسل رسائل لزبائن حقيقيين ولم تُعدّل بيانات الإنتاج، حالة النشر تُثبت بسجل GitHub وRailway.
